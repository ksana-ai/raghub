# Changelog

All notable changes to RAGHub will be documented in this file. The project uses
Semantic Versioning after its first tagged preview.

## [Unreleased]

### Added

- Open-source project governance, security policy, and release automation.
- Reproducible container build and PostgreSQL-backed integration CI.

### Security

- Upgraded the supported Go toolchain and vulnerable retrieval dependencies.

## [0.1.0-alpha] - Unreleased

- Deterministic Markdown ingestion and immutable document versions.
- PostgreSQL FTS, exact pgvector Dense retrieval, and fail-closed Hybrid RRF.
- Tenant and principal filtering, citations, stage traces, and strict offline
  evaluation over versioned smoke and benchmark datasets.
